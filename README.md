为北京析芒教育咨询有限公司「逻辑解剖」开发的独立自建微信小程序，功能包括认证准入、医生和从业者身份分流、课程交易和从业者招商。

## 本地开发

环境要求：Node.js ≥ 20、pnpm 10、Docker。

```bash
# 1. 安装依赖，构建共享包
pnpm install
pnpm build:shared

# 2. 启动 MySQL + Redis
pnpm db:up

# 3. 后端：配置环境变量，建表，写入种子数据（超级管理员 + 演示课程）
cd apps/server
cp .env.example .env
#   必填：DATA_ENCRYPTION_KEY=$(openssl rand -base64 32)
pnpm prisma:migrate
pnpm prisma:seed
cd ../..
pnpm dev:server            # http://localhost:3000 ，接口文档 http://localhost:3000/docs

# 4. 管理后台
pnpm dev:admin             # http://localhost:5173 ，默认账号见 .env 中的 SEED_ADMIN_*

# 5. 小程序
cp apps/miniapp/.env.example apps/miniapp/.env.development
pnpm dev:miniapp           # 用微信开发者工具导入 apps/miniapp/dist/dev/mp-weixin
#   或在浏览器调试 H5：pnpm --filter @luoji/miniapp dev:h5
```

后端 `.env` 里两个开发开关（生产环境开启会拒绝启动）：
- `WX_MOCK_LOGIN=true`：登录不请求微信接口，H5 和接口工具都能直接调试。
- `PAY_MOCK=true`：支付和退款走模拟网关并立即成功，商户号开通前可以完整联调下单、支付、退款。

## 课程体系与导航

按析芒教育「逻辑解剖」品牌资料梳理，后台分类为两级（种子脚本已预置）：

| 一级 | 二级 |
|---|---|
| 线下精品课（四大主题） | 核心框架课（精准解剖实操课 / 注射解剖闭门研习会）、临床转化课（注射在左、解剖在右）、风险应急课（“救”在眼前）、血管安全专项（驾驭血管的艺术） |
| 线上精品课（五大系列） | 胶原蛋白专区、玻尿酸专区、肉毒素 · SMAS、面部精细解剖、专题直播回放 |
| 公益讲堂 | 每日 60 秒、云学苑 |

小程序底部为 4 个 Tab：首页 / 课程 / 合作 / 我的（学习中心在「我的」里）。主色取自品牌蓝 `#2A5BD7`。

## 演示版（无需后端）

学员端可以编译成一个纯前端的 H5 演示版，在手机浏览器里直接体验：接口在浏览器本地模拟（`apps/miniapp/src/demo/`），课程、价格、优惠券等为拟定的占位数据，支付为模拟支付，提交认证 3 秒后自动通过，数据只保存在本机。

```bash
pnpm --filter @luoji/miniapp build:demo   # 产物在 apps/miniapp/dist/build/h5，可放到任意静态托管路径下
```

演示版只在 `--mode demo`（`.env.demo` 中 `VITE_DEMO=true`）时生效，正式构建不受影响。「我的 → 演示工具」可切换医生 / 从业者身份或重新开始体验。

## 后台账号与角色

首个超级管理员由种子脚本创建（`.env` 中的 `SEED_ADMIN_USERNAME` / `SEED_ADMIN_PASSWORD`），上线后请立即在「右上角 → 修改密码」中修改。其余账号在「系统 → 管理员」中创建：

| 角色 | 可访问 |
|---|---|
| 超级管理员 | 全部功能，含系统管理 |
| 运营 | 内容、用户、订单查看、营销、运营配置、招商线索 |
| 审核员 | 认证审核、用户 |
| 财务 | 订单、退款、导出 |

密码需 8~64 位且同时包含字母和数字。
